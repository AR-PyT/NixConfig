# Installed Packages

This document provides an overview of the installed packages, grouped by their functionality.

## System Utilities

- **overskride**: A tool for overriding system configurations.
- **iwgtk**: A GTK-based wireless network manager.
- **impala**: A tool for managing system configurations.
- **greetd.tuigreet**: A terminal-based greeter for the `greetd` display manager.
- **grimblast**: A screenshot tool for Wayland.
- **hyprcursor**: A cursor theme manager for Hyprland.
- **hyprpaper**: A wallpaper manager for Hyprland.
- **wl-clipboard**: A command-line clipboard utility for Wayland.
- **wlr-randr**: A tool for managing monitor settings on Wayland.
- **xwayland**: A compatibility layer to run X applications on Wayland.
- **hyprpicker**: A color picker tool for Hyprland.
- **hyprlock**: A screen locker for Hyprland.
- **hypridle**: An idle management tool for Hyprland.
- **brightnessctl**: A tool to control screen brightness.
- **usbutils**: Utilities for managing USB devices.
- **lshw**: A tool to list hardware configurations.
- **pciutils**: Utilities for managing PCI devices.
- **smartmontools**: Tools for monitoring the health of storage devices.
- **xdg-utils**: Utilities for integrating applications with the desktop environment.
- **killall**: A command to kill processes by name.

## Development Tools

- **python312**: Python programming language version 3.12.
- **gcc**: GNU Compiler Collection for compiling C and C++ programs.
- **clang**: A compiler for C, C++, and Objective-C.
- **cmake**: A build system generator.
- **git**: Version control system.
- **vim**: Text editor.
- **neovim**: An extended version of Vim.
- **nix-tree**: A tool to browse the Nix store.
- **vscode**: Visual Studio Code, a code editor.

## Terminal Utilities

- **kitty**: A terminal emulator.
- **fish**: A user-friendly command-line shell.
- **btop**: A resource manager for monitoring system performance.
- **ranger**: A terminal-based file manager.
- **wget**: A network downloader.
- **rsync**: A tool for synchronizing files and directories.
- **unzip**: A tool for extracting ZIP files.
- **unrar**: A tool for extracting RAR files.
- **zip**: A tool for creating ZIP files.
- **ripgrep**: A line-oriented search tool.
- **tree**: A directory listing command that produces a depth-indented listing of files.
- **cmatrix**: A terminal-based "Matrix" screensaver.
- **cowsay**: A configurable talking cow, written in Perl.
- **eza**: A modern replacement for `ls`.

## Audio and Video

- **pamixer**: A command-line mixer for PulseAudio.
- **alsa-utils**: Utilities for managing ALSA (Advanced Linux Sound Architecture).
- **pavucontrol**: A volume control tool for PulseAudio.
- **pipewire**: A server for handling audio and video streams.
- **qpwgraph**: A graph manager for PipeWire.
- **feh**: An image viewer.
- **mpv**: A media player.
- **vlc**: A media player.

## Applications

- **appimage-run**: A tool to run AppImages on NixOS.
- **firefox**: A web browser.
- **remmina**: A remote desktop client supporting RDP and VNC.
- **file-roller**: An archive manager.
- **pcmanfm**: A file manager.
- **p7zip**: A file archiver with high compression ratio.
- **wpsoffice**: An office suite.

## Typing Tutors

- **klavaro**: A touch typing tutor.
- **gtypist**: A typing tutor.
- **via**: A tool for configuring mechanical keyboards.

## Miscellaneous

- **wlsunset**: A tool to adjust the color temperature of your screen based on the time of day.
