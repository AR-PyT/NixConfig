# NixConfig

This repository contains a collection of GRUB themes organized into directories numbered from `0` to `59`. Each directory represents a unique GRUB theme that can be used to customize your bootloader.

## Structure

```
NixConfig/
├── 0/
├── 1/
├── 2/
...
├── 59/
```

Each directory contains the necessary files for a specific GRUB theme.

## Usage

1. Navigate to the desired theme directory (e.g., `0/`).
2. Follow the instructions provided in the directory to apply the theme to your GRUB configuration.

## Contributing

Feel free to submit pull requests to add new themes or improve existing ones. Ensure that each theme is placed in its respective numbered directory.
